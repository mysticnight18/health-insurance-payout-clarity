# CoverClarity

A polished, static student-project prototype for exploring health-insurance payout clarity.

## Preview

Open `index.html` in a modern browser. The sample interaction compares a hospital estimate with an insurer estimate provided by the visitor and shows the difference. It does not interpret policy terms, determine coverage, or predict a claim decision.

## Privacy and safety

This prototype has no backend. Values entered into the demo are not stored or transmitted. Do not enter real policy or health information.

## Hosting

Static site. Use the repository root as the project root; no build or install command is required.
